01 — About

Built for the field, not the demo.

Most of what I build lives where the internet is unreliable, the browser doubles as a payroll clerk, and Excel is a legitimate production environment. I design for that reality — local-first storage, exportable data, and interfaces people who aren't developers can trust.

My work spans progressive web apps for workforce management, live financial dashboards spanning multiple companies, desktop tools built with Tauri, and embedded systems running on real microcontrollers.

Based in the Philippines, I build primarily for Philippine business contexts — payroll compliance, peso-denominated reporting, and multi-language interfaces for mixed teams.

04 — Path

How this built up

Click a stage to expand. Chips jump to the related project.

Started with hardware — fingerprint sensors, RTC modules, and servo control — building the MB_303 biometric attendance system for EARIST Cavite.

Moved into spreadsheet-based business systems — inventory, invoicing, and payroll tools built with Python and openpyxl for real Philippine SMEs.

Built the Timecard PWA and the Financial Command Center — client-side apps using IndexedDB and Chart.js that work with zero server dependency.

Currently building dev-to-do, a Rust-backed desktop app, and exploring Branch — a git-native task manager concept.
